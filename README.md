## SE3100 Architecture Based Development: Sri Lanka Metrobus Service Platform

This repository holds our case study assignment for the SE3100 Architecture Based Development module at SLIIT (Year 3, Semester 1, 2026).

We were assigned Case Study 01, the Sri Lanka Metrobus Service Platform. Metrobus is a proposed metropolitan bus service for Greater Colombo. It needs one digital platform for passenger information, ticketing, fleet operations, route management, live vehicle tracking and service disruptions.

Our task was to analyse the case study, select a suitable architectural style, and document the proposed architecture with the C4 model.

### Contents

- `SE40`: the final report
- `C4-Diagrams/`: the C4 diagrams used in the report (System Context, Container, and one Component diagram per member)
